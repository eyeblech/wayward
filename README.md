# Wayward

Free coordinates for a walk, anywhere on earth. No account and no fee.

Share your location or search a place, set a radius, and roll a point:

- **Blind** — one uniform point inside the circle
- **Attractor** — a pocket where a cloud of random points clumps
- **Void** — a pocket that cloud left empty

Rolls use the browser’s cryptographic random generator. They are a prompt to go look, not a prediction. Stay on public paths.
